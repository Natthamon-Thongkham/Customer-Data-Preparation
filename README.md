# Data Preparation and Analysis Projects

### Project Overview

This repository contains two group assignments focused on data preparation, analysis, and visualization.

The **Customer Dashboard** project uses RFM analysis to explore customer purchasing behavior, identify customer segments, and suggest marketing approaches for different groups.

The **Titanic Passenger Survival Analysis** project examines passenger survival patterns based on gender, passenger class, and embarkation port.

Both projects involved preparing and reviewing data before presenting the findings through charts and presentation slides.

### Technologies & Tools

- **Data Preparation:** Microsoft Excel, Data Cleaning, and Filtering
- **Analysis Methods:** RFM Analysis and Exploratory Data Analysis (EDA)
- **Data Presentation:** Charts and Presentation Slides

### My Work

- Helped clean and filter parts of the datasets before analysis.
- Assisted with preparing and organizing presentation slides to explain the findings.

### Results

The Customer Dashboard project showed customer segments, purchasing patterns, and possible marketing approaches based on RFM analysis.

The Titanic analysis compared passenger survival patterns by gender, passenger class, and embarkation port using charts and data visualizations.

- **Customer dashboard .pdf** – Group presentation covering customer segmentation using RFM analysis, customer purchasing behavior, and marketing suggestions.
- **TITANIC_Analysis_G1.pdf** – Group presentation analyzing Titanic passenger survival patterns by gender, passenger class, and embarkation port.
